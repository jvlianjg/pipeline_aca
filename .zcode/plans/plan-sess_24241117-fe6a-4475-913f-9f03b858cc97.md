# Plan: Sistema de Inteligencia ACA — Frontend a medida

## Resumen
Construir una réplica fiel del mockup (https://7imfbjemz2vc4.kimi.page) como **frontend web a medida** (HTML + CSS + JS vanilla + Chart.js), servido por un **backend Python (Flask)** que lee los datos reales del pipeline y complementa con **datos de ejemplo (mock)** donde no existen aún (políticas, ICI, medios, temáticas, serie temporal).

## Decisiones de diseño (de la paleta real del mockup)
Paleta extraída del CSS del mockup (HSL → hex aproximado):
- **Fondo**: `#F5F5F0` (crema cálido, `hsl(60 9% 96%)`)
- **Tarjetas**: `#FFFFFF` / `#FAFAF8`
- **Texto principal**: `#1A1D23`
- **Texto muted**: `#5C6370` / `#9BA3B0`
- **Bordes**: `#E5E7EB` / `#F0F1F4`
- **Primary (navy)**: `#2E4A62` (gráfico + sidebar activo)
- **Secondary (verde)**: `#1E7A5F`
- **Chart teal**: `#3A8B8C` | **Chart amber**: `#D4953A` | **Chart terracotta**: `#C4523A` | **Chart lavender**: `#7E6BB0`
- **Tipografías**: títulos en *Instrument Serif* (serif elegante), cuerpo en *DM Sans* — ambas de Google Fonts
- **Layout**: sidebar fija izquierda (w-64), contenido max-w-1440, cards con `border-radius: .625rem`, sombras suaves

## Backend (`web/serve.py` + `web/data_gen.py`)

**`data_gen.py`** — genera datos de ejemplo coherentes y los guarda en `web/mock/` (ejecutado una sola vez):
1. **Temáticas**: agrupa los 29 docs reales por tema usando heurísticas sobre `filename` (fiscal, salud, empleo, competencia, ambiente, etc.) → `topics.json` con `{tema: [doc_ids]}` y III medio por tema (real).
2. **Serie temporal III**: 6 puntos mensuales (Feb–Jul 2026), tendencia estable partiendo del III medio real (0.638) → `time_series.json`.
3. **Políticas vinculadas**: ~12-15 políticas públicas mock (nombre, institución CCSS/MEP/MINAE/Hacienda/MTSS, número de ley, III score derivado del III real entre docs, adopción TOTAL/PARCIAL, fecha) → `policies.json`.
4. **ICI records**: eventos mock por canal (audiencias, citación_oficial, informe_técnico, menciones_medios, espacio_opinion) usando el esquema EXACTO de `src/indexing/ici.py` → se procesan con `compute_ici_all` real para producir `ici_results.json` (ICI político/medios/total por doc, **calculado con la fórmula real**).
5. **Cobertura mediática**: 247 menciones mock distribuidas → suma 385 interacciones (62% político / 38% medios como en el mockup).

**`serve.py`** — Flask con endpoints JSON:
- `GET /api/overview` → KPIs globales (III promedio, publicaciones, políticas, cobertura) — mezcla real + mock
- `GET /api/iii-evolution` → serie temporal
- `GET /api/ici-channels` → ICI político vs medios (serie)
- `GET /api/topics` → III por temática (barras)
- `GET /api/influence-distribution` → donut 62%/38%
- `GET /api/recent-matches` → tabla de coincidencias (políticas vinculadas)
- `GET /api/documents` → 29 docs reales
- `GET /api/document/<doc_id>` → detalle de un doc (propuestas reales + III)
- `GET /api/matrix/<component>` → matriz III o sub-componente (29×29 real)
- `GET /api/ranking` → ranking real por iii_medio
- `GET /api/proposals/<doc_id>` → propuestas reales

## Frontend (`web/static/`)

**`index.html`** — réplica del layout del mockup:
- **Sidebar** (w-64, bg `#2E4A62` navy): logo "A" + "Sistema de Inteligencia", nav con 5 items (Dashboard, Análisis, Canales, Auditoría, Configuración), avatar "JD" abajo.
- **Topbar**: título de sección + fecha "Julio 2026".
- **Área de contenido**: `<div id="view">` que se rellena por JS según la nav activa.

**`styles.css`** — diseño token-based replicando el mockup:
- Variables CSS con la paleta exacta (--bg, --card, --primary navy, --secondary green, --chart-*).
- Componentes: `.kpi-card`, `.chart-card`, `.data-table`, `.badge` (TOTAL=verde, PARCIAL=amber), `.pill`.
- Tipografías DM Sans + Instrument Serif vía @import de Google Fonts.
- Responsive: grid de KPIs (4 col → 2 → 1).

**`app.js`** — SPA vanilla:
- Router por hash (`#/dashboard`, `#/analisis`, etc.).
- **Vista Dashboard** (réplica exacta del mockup):
  - 4 KPI cards: III Promedio 67.3%, Publicaciones (reales: 29, mostrado como muestra el mockup con nota), Políticas Vinculadas, Cobertura Mediática.
  - Gráfico de línea: Evolución del III (6 meses).
  - Gráfico de líneas: Canales de Influencia (ICI-Político vs ICI-Medios).
  - Barras horizontales: Impacto por Temática (con % y conteo).
  - Donut: distribución de interacciones (62%/38%).
  - Tabla: Coincidencias Recientes (Publicación, Política, III, Adopción, Fecha).
- **Vista Análisis**: ranking real de documentos por iii_medio + selector de componente (III/Alineación/Coincidencia/Temporalidad) → heatmap 29×29 real.
- **Vista Canales**: detalle ICI por documento (calculado con fórmula real sobre records mock) + tabla por canal.
- **Vista Auditoría**: metodología (fórmulas III/ICI reales), pesos, ventana temporal, alcance y leyenda de qué es real vs mock.
- **Vista Configuración**: parámetros (proveedor IA, modelo embeddings, pesos III=1/3 c/u, α_ici=0.6).
- Charts con **Chart.js** (CDN): line, bar, doughnut. Heatmap con canvas custom o librería ligera.

## Diferenciación real vs. mock (transparencia)
Cada sección mock llevará un badge discreto "Datos de ejemplo" para no inducir a error; los datos reales (documentos, propuestas, matriz III, ranking) se muestran sin badge.

## Ejecución
```bash
python web/serve.py   # → http://localhost:5000
```
No requiere build step (todo vanilla + CDN). Flask ya es dependencia implícita del ecosistema; si no está, se añade al requirements.
